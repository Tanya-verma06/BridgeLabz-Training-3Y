Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(100%);

Media Queries

Apply styles according to screen size.

@media (max-width: 700px)

Responsive Design

Make websites adapt to different devices.

width: 100%;

Typography

Scale text according to viewport size.

font-size: clamp(1rem, 3vw, 2rem);
